이 와이어프레임의 계획은 규칙 기반으로 동작하고 기록은 현재 브라우저에 저장돼요.

다음 단계 후보

리그·배지·공개 루틴·친구 매칭은 핵심 운동 흐름을 다듬은 뒤 검토해요.

발표용 · AI 연결 설계와 v0.2 시연 범위 보기

연결 흐름

모바일 화면 → 서버 또는 프록시 → LLM → 금기 부위 필터·강도 상한 검사 → 주간 계획. AI 응답이 실패하거나 안전 검사를 통과하지 못하면 검증된 규칙 계획으로 전환합니다. 정적 페이지에는 API 키를 넣지 않습니다.

입력과 프롬프트 예시

입력: {goal, level, sessionsPerWeek, minutesPerSession, avoidAreas}
지시: 초보자의 강도는 낮게 유지한다. avoidAreas에 부담을 줄 수 있는 동작은 추천하지 않는다. 통증·질환은 전문가 상담을 안내한다. 정해진 JSON 형식으로만 답한다.

기대 출력 형식

{"source":"ai","summary":"...","days":[{"day":"월","title":"...","minutes":20,"exercises":[{"name":"...","sets":1}]}],"excludedMoves":["..."],"safetyNotes":["..."]}

현재 파일은 서버와 AI가 연결되지 않은 클릭형 와이어프레임입니다. 선택한 부위가 계획과 제외 동작에 반영되는 흐름을 규칙 기반으로 시연합니다.

v0.2 시연 안내

운동 조건을 고르면 규칙 기반 예시 계획이 만들어집니다. AI 연결과 실제 사용자 순위는 아직 제공되지 않아요.

이 안내는 첫 방문에 한 번 표시됩니다.
