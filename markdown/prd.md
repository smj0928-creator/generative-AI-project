## v0.1 — 기존 프로토타입

> **제품 버전:** 0.1  
> **상태:** 기존 프로토타입 기준본  
> **기준:** 저장소의 v0.1 프로토타입과 현재 보존된 와이어프레임  
> **용도:** v0.2 이후 버전과 비교·발표하기 위한 이전 버전 기록

### 1. 제품 개요

AI트레이너 v0.1은 사용자가 운동 목표와 수준, 주당 운동 횟수, 1회 운동 시간 및 주의사항을 입력하고 주간 운동 계획과 완료 기록을 확인하는 모바일 웹 프로토타입이다. 운동 계획은 미리 준비된 템플릿과 규칙으로 구성된다. 실제 생성형 AI, 계정 로그인, 서버 저장은 연결되어 있지 않으며 데모 기록은 브라우저의 `localStorage`에 저장된다.

### 2. 대상 사용자와 문제

- 운동을 처음 시작하거나 꾸준한 운동 습관을 만들고 싶은 사람
- 목표와 현재 수준에 맞는 주간 운동 계획을 간단히 확인하고 싶은 사람
- 완료 기록과 성취 피드백으로 운동 진행 상황을 관리하고 싶은 사람

초보 사용자는 운동 계획을 직접 구성하기 어렵고, 계획을 세운 뒤에도 주간 진행 상황과 성취를 한곳에서 확인하기 어렵다.

### 3. 핵심 사용자 흐름

1. 시작 화면에서 둘러보기 또는 다음을 눌러 앱에 진입한다.
2. 홈에서 운동 목표, 수준, 주당 횟수, 운동 시간과 주의사항을 입력한다.
3. 주간 계획을 생성하고 홈 또는 플랜 화면에서 요일별 운동을 확인한다.
4. 운동 상세와 기본 안전 안내를 살펴본다.
5. 운동 완료를 기록하고 성장 화면에서 진행률과 배지를 확인한다.
6. 함께 화면에서 데모 리그와 공개 루틴을 살펴보고, 설정에서 닉네임을 저장한다.

### 4. 기능 범위

| 기능 | v0.1 기준 |
|---|---|
| 운동 조건 입력 | 목표, 수준, 주당 운동 횟수, 운동 시간, 주의사항 입력 |
| 주간 계획 | 목표별 사전 정의 운동 템플릿을 이용한 규칙 기반 계획 생성 |
| 운동 상세 | 운동 구성과 기본 안전 안내 표시 |
| 완료 기록 | 운동 완료 상태와 진행 현황 저장 |
| 성장 | 완료 횟수, 주간 진행률, 누적 기록 및 배지 표시 |
| 준비 체크리스트 | 운동 준비 항목 체크 및 브라우저 내 저장 |
| 함께 | 가상 리그 순위, 승급 조건, 공개 루틴과 매칭 데모 표시 |
| 설정 | 닉네임 저장, 데모 기록 초기화 |
| 저장 | 동일 브라우저의 `localStorage`에 데이터 저장 |

### 5. 화면 구조

하단 탭 기준으로 홈, 플랜, 성장, 함께, 설정 화면을 제공한다. 시작 화면과 운동 상세는 주요 화면에서 이어지는 흐름으로 제공한다.

### 6. 비범위 및 한계

- 실제 생성형 AI 모델/API를 통한 추천
- 실제 회원가입, 로그인, 계정 인증 및 기기 간 데이터 동기화
- 서버 데이터베이스, 실시간 사용자 순위와 멀티플레이
- 실제 트레이너 인증, 푸시 알림, 의료적 평가나 운동 처방

리그와 매칭은 시연용 데이터다. 운동 안전 안내는 기본 정보이며 의료 또는 전문 처방을 대체하지 않는다.

### 7. 완료 기준

- 운동 조건을 입력하고 주간 계획을 확인할 수 있다.
- 운동 상세와 기본 안전 안내를 확인할 수 있다.
- 완료 기록에 따라 성장 화면 정보가 갱신된다.
- 닉네임과 주요 데모 기록이 같은 브라우저에서 유지된다.
- 실제 AI·로그인·서버 기능이 연결되지 않았다는 점을 명확히 알린다.

## v0.2 — 공개 루틴과 마이페이지 중심 프로토타입

> **제품 버전:** 0.2  
> **상태:** 프로토타입 수정 기준  
> **기준:** v0.1 프로토타입, 기존 개선 피드백, 홈 화면에 대한 최신 사용자 의견  
> **이전 버전:** [v0.1](#v01--기존-프로토타입)

### 1. 제품 방향

AI트레이너 v0.2는 처음 방문한 사람도 로그인 없이 공개 트레이너 루틴을 둘러보고, 원하는 루틴을 참고해 운동을 시작할 수 있는 모바일 웹 프로토타입이다. 사용자가 제안한 핵심 변경은 **홈 화면의 ‘이번 주 운동’을 마이페이지 상단으로 옮기고, 그 자리에 인기 트레이너 루틴을 배치하는 것**이다. 방문자는 맞춤 계획을 입력하기 전에 실제로 어떤 운동 구성이 있는지 먼저 살펴볼 수 있어야 한다.

루틴은 공개를 기본 방향으로 한다. 비로그인 방문자도 목록과 상세 내용을 볼 수 있고, 로그인이나 가입을 열람 조건으로 요구하지 않는다. ‘내 플랜에 담기’는 현재 프로토타입의 저장 방식에 맞춰 시연하며, 필요한 경우 가입 없이 로컬 플랜에 추가한다. 향후 실제 계정 기능을 도입하더라도 공개 열람은 유지한다.

계획 생성은 실제 AI 연결 전까지 규칙 기반 시연이라고 표시한다. 향후 AI 입력·응답·안전 검증·실패 시 대체 경로를 문서화하며 정적 페이지에 API 키를 넣지 않는다. 가상 트레이너·팔로워·인기 순위·인증 표시는 실제 정보로 오해되지 않도록 데모임을 분명히 표시하거나 검증된 정보만 사용한다.

### 2. 대상 사용자와 핵심 흐름

- **대상 사용자:** 처음 방문해 루틴을 탐색하는 비회원, 공개 루틴을 참고하거나 자신만의 주간 계획을 관리하려는 사용자
- **해결할 문제:** 첫 방문자에게 맞춤 조건 입력부터 요구하지 않고 운동 콘텐츠를 먼저 보여 준다. 홈과 플랜에 주간 일정이 중복 노출되는 혼란을 줄인다.
- **방문자 흐름:** 홈 진입 → 인기 트레이너 루틴 미리보기 → 루틴 상세와 운동 가이드 확인 → 내 플랜에 담기 또는 맞춤 계획 만들기
- **사용자 흐름:** 마이페이지 상단에서 주간 일정 확인 → 운동 상세와 안전 안내 확인 → 운동 완료 기록 → 마이페이지에서 현황·배지 확인

### 3. 범위와 우선순위

| 구분 | 범위 |
|---|---|
| Must | 비로그인 공개 루틴 열람, 홈의 인기 트레이너 루틴 노출, 루틴 상세 확인, 루틴을 플랜에 담기, 주간 운동을 마이페이지 상단으로 이동, 배지를 마이페이지로 통합, 앱 설정 별도 분리, 운동 조건 반영, 상시 안전 안내 |
| Should | 루틴 출처·데이터 성격 표시, 규칙 기반 시연과 향후 AI 설계 구분, 접근 가능한 메뉴와 상태 안내, README·배포 정보 정리 |
| Later | 실제 트레이너 계정·인증과 인기 지표 연동, 친구 매칭, 푸시 알림, 실제 계정 동기화 및 서버 저장 |

v0.1은 발표와 비교를 위해 보존한다. v0.2에서는 홈에 개인 주간 운동 목록을 표시하지 않고, 주간 운동을 마이페이지 상단에서 확인한다. 플랜은 주간 달성률과 계획 목록을 관리하고, 배지는 마이페이지에 모은다. 앱 설정은 마이페이지에서 진입하는 별도 화면으로 분리한다. 공개 루틴은 홈의 핵심 발견 기능으로 유지한다. 동작하지 않는 알림 토글과 실제 데이터로 오해할 수 있는 순위·인증 표현은 제거하거나 데모 표시를 붙인다. 전화번호 입력은 받지 않는다.

### 4. 화면 구조와 동작

| 화면/영역 | 주요 내용 | 동작 또는 예외 | 우선순위 |
|---|---|---|---|
| 홈 상단 | 서비스 소개와 기존 프로토타입의 인사/활동 요약 | 비회원도 바로 홈을 볼 수 있고 로그인 화면에 가로막히지 않음 | Must |
| 홈: 인기 트레이너 루틴 | 공개 루틴 카드, 트레이너 표시, 목표·수준·운동 장소·방식·예상 시간 | ‘루틴 보기’로 상세 이동, ‘내 플랜에 담기’로 플랜에 추가 | Must |
| 루틴 상세 | 운동 순서·세트/횟수·시간·필요 도구·가이드 미디어·안전 주의 | 비로그인 열람 가능, 미디어 출처와 라이선스 표시 | Must |
| 홈: 맞춤 계획 만들기 | 목표, 수준, 주당 횟수, 시간, 운동 장소, 운동 방식, 주의 부위 | 입력값을 계획 생성에 반영하고 규칙 기반 시연임을 표시 | Must |
| 플랜 | 주간 달성률, 개인 계획 목록, 준비 체크리스트 | 생성한 계획과 공개 루틴에서 담은 운동을 확인 | Must |
| 마이페이지 | 이번 주 운동 선택기와 운동 카드, 활동 현황, 프로필, 배지 | 주간 운동이 상단에 오고 배지 컬렉션이 이 화면에 표시됨 | Must |
| 앱 설정 | 알림 준비 상태, 안전 안내 상시 표시, 프로토타입·데이터 안내 | 마이페이지에서 별도 진입; 프로필·배지와 구분 | Should |
| 운동 상세 | 운동 안내 및 항상 보이는 안전 문구 | 통증·어지러움 시 중단, 부상·질환이 있으면 전문가 상담 안내 | Must |
| 기록/성장 | 완료 횟수, 주간 달성률 등 기존 프로토타입의 기록 | 기록이 없으면 시작 안내를 표시하고 근거 없는 순위는 표시하지 않음 | Should |
| 마이페이지 프로필 | 닉네임 확인·수정, 운동 현황·배지 확인 | 프로필 정보와 앱 환경 설정을 분리 | Must |

### 5. 기능 요구사항 및 완료 조건

| ID | 요구사항 | 확인 가능한 완료 조건 | 우선순위 |
|---|---|---|---|
| FR-01 | 비회원에게 공개 루틴을 제공한다. | 새 브라우저에서도 로그인/가입 없이 홈의 루틴 카드와 상세 페이지를 열 수 있다. | Must |
| FR-02 | 홈에서 인기 트레이너 루틴을 먼저 발견하게 한다. | 기존 홈의 ‘이번 주 운동’ 영역은 사라지고 그 위치에 루틴 카드/목록이 표시된다. | Must |
| FR-03 | 주간 운동을 마이페이지 상단에서 관리한다. | 요일별 주간 일정과 완료 상태가 마이페이지 상단에 표시되고 홈과 중복되지 않는다. 플랜에는 전체 계획 목록이 표시된다. | Must |
| FR-04 | 공개 루틴 상세를 제공한다. | 루틴의 목표, 수준, 운동 장소·방식, 예상 시간, 동작 구성과 필요한 도구를 확인할 수 있다. | Must |
| FR-05 | 루틴을 개인 플랜에 담는다. | 버튼 동작 후 해당 루틴이 플랜에 나타나며 중복 추가 방지 또는 중복 상태 안내가 제공된다. | Must |
| FR-06 | 공개 루틴과 맞춤 계획 경로를 함께 제공한다. | 홈에서 공개 루틴을 둘러보거나 맞춤 계획을 만들 수 있고 어느 쪽도 강제하지 않는다. | Must |
| FR-07 | 운동 환경과 사용자의 주의점을 계획에 반영한다. | 목표·수준·횟수·시간·장소·방식·주의 부위가 계획 요약/동작 구성에 반영된다. | Must |
| FR-08 | 실제 AI 연동 여부를 정확히 알린다. | 규칙 기반 결과를 AI가 생성했다고 표시하지 않는다. 향후 연동은 서버/프록시를 사용하고 정적 페이지에 키를 두지 않는다. | Must |
| FR-09 | 운동 안전 안내를 항상 제공한다. | 운동 상세에서 안전 안내를 끌 수 없고 통증·어지러움 시 중단 및 전문가 상담 문구가 보인다. | Must |
| FR-10 | 데모·트레이너 데이터를 오해 없이 표시한다. | 가상 이름·팔로워 수·순위·인증이 있으면 데모임을 명시하고 실제 인증/인기도처럼 단정하지 않는다. | Must |
| FR-11 | 가이드 미디어의 사용 권리를 확인할 수 있게 한다. | 각 영상·이미지의 출처와 라이선스/사용 조건을 기록하고 출처 불명 자료는 공개 콘텐츠로 사용하지 않는다. | Should |
| FR-12 | 모바일·키보드 접근성을 유지한다. | 주요 버튼과 탭에 의미 있는 이름이 제공되고 키보드 포커스를 확인할 수 있다. | Should |

### 6. 공개 루틴과 미디어 기준

- 공개 루틴은 로그인 없이 목록·상세를 볼 수 있다. 방문자는 운동 동작, 목표, 난이도, 장소, 방식, 예상 시간, 준비물을 보고 자신에게 맞는지 판단한다.
- 실제 트레이너가 제공한 콘텐츠가 아니라 데모 루틴이면 ‘예시 루틴’ 또는 ‘데모 데이터’로 표시한다. 실제 인물·인증·팔로워 수·인기도를 근거 없이 주장하지 않는다.
- 가이드 영상·사진은 직접 제작했거나 명시된 라이선스에 따라 재사용 가능한 자료만 사용한다. 자료별 출처와 라이선스를 데이터에 보존하고, 출처가 확인되지 않는 항목은 게시하지 않는다.
- 미디어를 불러오지 못해도 동작 이름과 텍스트 설명으로 루틴의 핵심을 이해할 수 있어야 한다.

### 7. AI 계획 생성 설계와 안전

현재 프로토타입의 계획 생성은 규칙 기반 시연이다. 향후 실제 AI를 연결할 때는 화면에서 조건 수집 → 서버/프록시 입력 검증 → 모델 요청 → 응답 스키마 검증 → 금기 동작 필터와 강도 상한 재검사 → 사용자에게 출처와 안전 정보를 표시한다. 실패·시간 초과·검증 실패 시 안전 필터를 통과한 규칙 기반 계획으로 대체하고 대체 생성임을 알린다.

입력에는 목표·수준·주당 횟수·회당 시간·운동 장소·운동 방식·주의 부위를 포함한다. 출력에는 요일, 동작, 세트/횟수 또는 시간, 강도, 조정 사유, 안전 문구를 포함한다. 통증이나 질환을 진단하거나 치료법을 제시하지 않는다. 입문자에게 고강도 동작을 자동 추천하지 않고, 안전한 대체 계획을 만들 수 없으면 무리하게 생성하지 말고 사용자에게 조건 재검토를 안내한다.
