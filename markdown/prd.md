## v0.1 — 기존 프로토타입

> **제품 버전:** 0.1  
> **상태:** 기존 프로토타입 기준본  
> **기준:** 저장소의 v0.1 프로토타입과 현재 보존된 와이어프레임  
> **용도:** v0.2 이후 버전과 비교·발표하기 위한 이전 버전 기록

### 1. 제품 개요

AI트레이너 v0.1은 사용자가 운동 목표와 수준, 주당 운동 횟수, 1회 운동 시간 및 주의사항을 입력하고 주간 운동 계획과 완료 기록을 확인하는 모바일 웹 프로토타입이다. 운동 계획은 미리 준비된 템플릿과 규칙으로 구성된다. 실제 생성형 AI, 계정 로그인, 서버 저장은 연결되어 있지 않으며 데모 기록은 브라우저의 `localStorage`에 저장된다.

### 2. 대상 사용자와 문제

- 운동을 처음 시작하거나 꾸준한 운동 습관을 만들고 싶은 사람
- 목표와 현재 수준에 맞는 주간 운동 계획을 간단히 확인하고 싶은 사람
- 완료 기록과 성취 피드백으로 운동 진행 상황을 관리하고 싶은 사람

초보 사용자는 운동 계획을 직접 구성하기 어렵고, 계획을 세운 뒤에도 주간 진행 상황과 성취를 한곳에서 확인하기 어렵다.

### 3. 핵심 사용자 흐름

1. 시작 화면에서 둘러보기 또는 다음을 눌러 앱에 진입한다.
2. 홈에서 운동 목표, 수준, 주당 횟수, 운동 시간과 주의사항을 입력한다.
3. 주간 계획을 생성하고 홈 또는 플랜 화면에서 요일별 운동을 확인한다.
4. 운동 상세와 기본 안전 안내를 살펴본다.
5. 운동 완료를 기록하고 성장 화면에서 진행률과 배지를 확인한다.
6. 함께 화면에서 데모 리그와 공개 루틴을 살펴보고, 설정에서 닉네임을 저장한다.

### 4. 기능 범위

| 기능 | v0.1 기준 |
|---|---|
| 운동 조건 입력 | 목표, 수준, 주당 운동 횟수, 운동 시간, 주의사항 입력 |
| 주간 계획 | 목표별 사전 정의 운동 템플릿을 이용한 규칙 기반 계획 생성 |
| 운동 상세 | 운동 구성과 기본 안전 안내 표시 |
| 완료 기록 | 운동 완료 상태와 진행 현황 저장 |
| 성장 | 완료 횟수, 주간 진행률, 누적 기록 및 배지 표시 |
| 준비 체크리스트 | 운동 준비 항목 체크 및 브라우저 내 저장 |
| 함께 | 가상 리그 순위, 승급 조건, 공개 루틴과 매칭 데모 표시 |
| 설정 | 닉네임 저장, 데모 기록 초기화 |
| 저장 | 동일 브라우저의 `localStorage`에 데이터 저장 |

### 5. 화면 구조

하단 탭 기준으로 홈, 플랜, 성장, 함께, 설정 화면을 제공한다. 시작 화면과 운동 상세는 주요 화면에서 이어지는 흐름으로 제공한다.

### 6. 비범위 및 한계

- 실제 생성형 AI 모델/API를 통한 추천
- 실제 회원가입, 로그인, 계정 인증 및 기기 간 데이터 동기화
- 서버 데이터베이스, 실시간 사용자 순위와 멀티플레이
- 실제 트레이너 인증, 푸시 알림, 의료적 평가나 운동 처방

리그와 매칭은 시연용 데이터다. 운동 안전 안내는 기본 정보이며 의료 또는 전문 처방을 대체하지 않는다.

### 7. 완료 기준

- 운동 조건을 입력하고 주간 계획을 확인할 수 있다.
- 운동 상세와 기본 안전 안내를 확인할 수 있다.
- 완료 기록에 따라 성장 화면 정보가 갱신된다.
- 닉네임과 주요 데모 기록이 같은 브라우저에서 유지된다.
- 실제 AI·로그인·서버 기능이 연결되지 않았다는 점을 명확히 알린다.

## v0.2 — 공개 루틴과 마이페이지 중심 프로토타입

> **제품 버전:** 0.2  
> **상태:** 프로토타입 수정 기준  
> **기준:** v0.1 프로토타입, 기존 개선 피드백, 홈 화면에 대한 최신 사용자 의견  
> **이전 버전:** [v0.1](#v01--기존-프로토타입)

### 1. 제품 방향

AI트레이너 v0.2는 처음 방문한 사람도 로그인 없이 공개 트레이너 루틴을 둘러보고, 원하는 루틴을 참고해 운동을 시작할 수 있는 모바일 웹 프로토타입이다. 사용자가 제안한 핵심 변경은 **홈 화면의 ‘이번 주 운동’을 마이페이지 상단으로 옮기고, 그 자리에 인기 트레이너 루틴을 배치하는 것**이다. 방문자는 맞춤 계획을 입력하기 전에 실제로 어떤 운동 구성이 있는지 먼저 살펴볼 수 있어야 한다.

루틴은 공개를 기본 방향으로 한다. 비로그인 방문자도 목록과 상세 내용을 볼 수 있고, 로그인이나 가입을 열람 조건으로 요구하지 않는다. ‘내 플랜에 담기’는 현재 프로토타입의 저장 방식에 맞춰 시연하며, 필요한 경우 가입 없이 로컬 플랜에 추가한다. 향후 실제 계정 기능을 도입하더라도 공개 열람은 유지한다.

계획 생성은 실제 AI 연결 전까지 규칙 기반 시연이라고 표시한다. 향후 AI 입력·응답·안전 검증·실패 시 대체 경로를 문서화하며 정적 페이지에 API 키를 넣지 않는다. 가상 트레이너·팔로워·인기 순위·인증 표시는 실제 정보로 오해되지 않도록 데모임을 분명히 표시하거나 검증된 정보만 사용한다.

### 2. 대상 사용자와 핵심 흐름

- **대상 사용자:** 처음 방문해 루틴을 탐색하는 비회원, 공개 루틴을 참고하거나 자신만의 주간 계획을 관리하려는 사용자
- **해결할 문제:** 첫 방문자에게 맞춤 조건 입력부터 요구하지 않고 운동 콘텐츠를 먼저 보여 준다. 홈과 플랜에 주간 일정이 중복 노출되는 혼란을 줄인다.
- **방문자 흐름:** 홈 진입 → 인기 트레이너 루틴 미리보기 → 루틴 상세와 운동 가이드 확인 → 내 플랜에 담기 또는 맞춤 계획 만들기
- **사용자 흐름:** 마이페이지 상단에서 주간 일정 확인 → 운동 상세와 안전 안내 확인 → 운동 완료 기록 → 마이페이지에서 현황·배지 확인

### 3. 범위와 우선순위

| 구분 | 범위 |
|---|---|
| Must | 비로그인 공개 루틴 열람, 홈의 인기 트레이너 루틴 노출, 루틴 상세 확인, 루틴을 플랜에 담기, 주간 운동을 마이페이지 상단으로 이동, 배지를 마이페이지로 통합, 앱 설정 별도 분리, 운동 조건 반영, 상시 안전 안내 |
| Should | 루틴 출처·데이터 성격 표시, 규칙 기반 시연과 향후 AI 설계 구분, 접근 가능한 메뉴와 상태 안내, README·배포 정보 정리 |
| Later | 실제 트레이너 계정·인증과 인기 지표 연동, 친구 매칭, 푸시 알림, 실제 계정 동기화 및 서버 저장 |

v0.1은 발표와 비교를 위해 보존한다. v0.2에서는 홈에 개인 주간 운동 목록을 표시하지 않고, 주간 운동을 마이페이지 상단에서 확인한다. 플랜은 주간 달성률과 계획 목록을 관리하고, 배지는 마이페이지에 모은다. 앱 설정은 마이페이지에서 진입하는 별도 화면으로 분리한다. 공개 루틴은 홈의 핵심 발견 기능으로 유지한다. 동작하지 않는 알림 토글과 실제 데이터로 오해할 수 있는 순위·인증 표현은 제거하거나 데모 표시를 붙인다. 전화번호 입력은 받지 않는다.

### 4. 화면 구조와 동작

| 화면/영역 | 주요 내용 | 동작 또는 예외 | 우선순위 |
|---|---|---|---|
| 홈 상단 | 서비스 소개와 기존 프로토타입의 인사/활동 요약 | 비회원도 바로 홈을 볼 수 있고 로그인 화면에 가로막히지 않음 | Must |

### 6. 공개 루틴과 미디어 기준

- 공개 루틴은 로그인 없이 목록·상세를 볼 수 있다. 방문자는 운동 동작, 목표, 난이도, 장소, 방식, 예상 시간, 준비물을 보고 자신에게 맞는지 판단한다.
- 실제 트레이너가 제공한 콘텐츠가 아니라 데모 루틴이면 ‘예시 루틴’ 또는 ‘데모 데이터’로 표시한다. 실제 인물·인증·팔로워 수·인기도를 근거 없이 주장하지 않는다.
- 가이드 영상·사진은 직접 제작했거나 명시된 라이선스에 따라 재사용 가능한 자료만 사용한다. 자료별 출처와 라이선스를 데이터에 보존하고, 출처가 확인되지 않는 항목은 게시하지 않는다.
- 미디어를 불러오지 못해도 동작 이름과 텍스트 설명으로 루틴의 핵심을 이해할 수 있어야 한다.

### 7. AI 계획 생성 설계와 안전

현재 프로토타입의 계획 생성은 규칙 기반 시연이다. 향후 실제 AI를 연결할 때는 화면에서 조건 수집 → 서버/프록시 입력 검증 → 모델 요청 → 응답 스키마 검증 → 금기 동작 필터와 강도 상한 재검사 → 사용자에게 출처와 안전 정보를 표시한다. 실패·시간 초과·검증 실패 시 안전 필터를 통과한 규칙 기반 계획으로 대체하고 대체 생성임을 알린다.

입력에는 목표·수준·주당 횟수·회당 시간·운동 장소·운동 방식·주의 부위를 포함한다. 출력에는 요일, 동작, 세트/횟수 또는 시간, 강도, 조정 사유, 안전 문구를 포함한다. 통증이나 질환을 진단하거나 치료법을 제시하지 않는다. 입문자에게 고강도 동작을 자동 추천하지 않고, 안전한 대체 계획을 만들 수 없으면 무리하게 생성하지 말고 사용자에게 조건 재검토를 안내한다.

### 1. 목표와 이전 버전 대비 변경

v0.8은 교수 피드백 2차와 사용자 검토를 반영해 홈·계획·개인 기록의 역할을 분명히 하고, 운동을 이어 가는 과정을 날짜로 확인하게 한다. 로그인 회원은 초대 코드를 이용해 실제 계정끼리 친구를 맺고 연속 운동 일수를 비교한다. 운동 계획 생성 방식은 여전히 규칙 기반이며 AI 호출을 했다고 표현하지 않는다.

| 영역 | v0.7 | v0.8 |
|---|---|---|
| 홈 | 통계와 계획 입력 중심 | 중복 통계를 줄이고 다음 운동·계획 입력·공개 루틴에 집중 |
| 계획 | `플랜` 탭과 다른 화면에 주간 운동 중복 | `내 운동`에 주간 목록·달성률·준비 체크리스트 배치 |

### 2. 사용자와 핵심 흐름

1. **게스트:** 홈의 공개 루틴을 살펴보고 운동 조건을 선택해 계획을 만든다. 계획과 완료 상태는 현재 브라우저에 저장한다. 함께 탭은 로그인 안내를 보여 준다.
2. **로그인 회원:** 이메일로 로그인하고 주간 계획을 만들거나 복원한다. 운동 완료 뒤 내 운동의 달성률과 마이페이지 달력을 확인한다. 계획과 완료 기록은 Supabase에 저장한다.
3. **친구 초대:** 함께 화면에서 자신의 8자리 초대 코드를 공유한다. 상대가 코드를 입력해 요청하면 받은 사용자가 수락 또는 거절한다. 수락 후 양쪽의 친구 목록에서 닉네임과 연속 운동 일수를 볼 수 있다. 친구 삭제도 가능하다.

### 4. 화면 및 데이터 규칙

- **홈:** 운동 목표, 수준, 주당 횟수, 1회 시간, 장소, 방식을 선택한다. 메모는 참고용이며 계획을 바꾸지 않는다. 공개 트레이너 루틴 한 명은 비회원도 볼 수 있다.
- **내 운동:** 선택 조건에 맞는 템플릿으로 주간 계획을 만들고 상세 가이드·완료 상태·달성률을 확인한다. 계획 재생성은 현재 계획의 완료 상태를 초기화하지만 과거 완료 날짜 기록은 보존한다.
- **마이페이지:** 현재 계획의 완료 횟수·시간, 배지와 실제 완료 날짜 달력을 보여 준다. 과거 버전의 날짜 없는 게스트 기록은 달력에 임의로 배치하지 않는다.
- **함께:** 게스트는 로그인 안내를 본다. 로그인 회원은 실제 친구 요청 영역과 기존 시연용 리그·프로필을 구분해서 본다. 요청 목록은 탭 재진입이나 새로고침 버튼으로 갱신한다.
- **저장:** 게스트 상태는 `localStorage`에 저장한다. 로그인 회원의 계획·완료 상태는 `user_plans`, 완료 날짜는 `workout_logs`, 친구 프로필과 요청은 `friend_profiles`·`friend_requests`에 저장한다. `supabase/v08-friends.sql`에 친구 접근 규칙과 요청 함수가 있다.
- **개인정보:** 친구 요청 당사자만 요청을 조회하고, 서로 수락한 친구만 운동 날짜를 비교할 수 있다. 비로그인 조회는 허용하지 않는다. 초대 코드는 이메일 대신 공유한다.

### 5. 검증 결과와 알려진 한계

2026-11-18에 v0.8 검토본의 달력 표시와 월 이동, GitHub Pages 파일 배포, Supabase 친구 테이블·요청 함수 생성, 두 친구 테이블의 행 단위 접근 제한, 비로그인 운동 날짜 조회 결과가 빈 목록임을 확인했다. 최종 실행본의 배포 주소는 README에 기록한다.

- **추가 검증:** 두 실제 로그인 계정으로 초대 코드 입력 → 요청 → 수락 → 친구 연속 일수 표시 → 삭제까지의 전체 흐름은 아직 확인하지 못했다. 신규 회원가입과 다른 기기의 기록 복원도 추가 검증 대상이다.
- **이전 기록:** v0.7 이전의 날짜 없는 게스트 완료 기록은 달력에 표시하지 않는다. v0.7의 일부 서버 완료 시각은 당시 동기화 과정에서 갱신됐을 수 있으므로 정확한 과거 운동일로 단정하지 않는다.
- **시연 데이터:** 리그 순위, 인증 표시, 공개 트레이너의 인기도, 비슷한 운동 친구 및 일부 타인 프로필·운동 기록은 실제 회원 데이터가 아니다. 실제 친구 기능과 시연용 친구 매칭은 별개다.
- **범위 밖:** 생성형 AI 호출, 참고용 메모의 추천 반영, 실제 사용자 기반 리그, 푸시 알림, 모든 운동 가이드 미디어의 검증은 v0.8에 포함하지 않는다.

## v0.9 — Gemini 주간 계획 생성 초안

> **작성일:** 2026-11-24<br>
> **기준:** [v0.8 보존 실행본](../versions/v0.8/)<br>
> **상태:** 코드와 모의 응답 테스트 완료. Supabase 함수 배포, Gemini 키 등록, 실제 응답 및 공개 화면 검증 전.

### 1. 목표와 변경 범위

v0.8의 화면, 회원 기록, 운동 달력, 친구 기능은 유지한다. 주간 운동 계획 생성에서 Gemini가 **사전 검토한 운동 템플릿 중 선택**하게 한다. 선택 결과를 서버가 다시 확인하며, 유효하지 않은 결과는 대체 계획으로 표시한다. AI가 운동 동작이나 의료 조언을 새로 작성하지 않는다.

| 항목 | v0.8 | v0.9 목표 |
|---|---|---|
| 계획 선택 | 브라우저 규칙 기반 | Supabase Edge Function을 통한 Gemini API 호출 |
| 참고 메모 | 추천에 반영되지 않음 | 서버에서 금기 후보를 먼저 제외하고 AI 선택에 참고. 질환·수술 관련 메모는 중단 |
| 데이터 출처 | Supabase 운동 템플릿, 장애 시 로컬 JSON | 서버의 활성 운동 템플릿 ID만 AI가 선택. 연결 실패 시 대체 계획임을 표시 |
| API 키 | 없음 | Supabase 서버 비밀 설정에만 보관 |
| 저장 | 게스트 로컬, 회원 Supabase | 기존 저장 흐름 유지. 계획 출처를 함께 기록 |

### 2. 요구사항과 수용 기준

| ID | 요구사항 | 수용 기준 | 상태 |
|---|---|---|---|
| FR-09-01 | 실제 Gemini 모델을 호출한다 | 서버의 `generate-plan` 요청이 Gemini `generateContent`로 전달되고 응답 출처가 `gemini`로 표시된다 | 모의 테스트 완료 · 실제 호출 전 |
| FR-09-02 | 입력 조건을 지킨다 | 목표, 수준, 횟수, 시간, 장소, 방식이 결과와 일치한다 | 코드 테스트 완료 |
| FR-09-03 | 운동 목록을 제한한다 | 모델이 없는 ID나 허용되지 않는 장소·방식의 운동을 반환해도 화면에 표시하지 않는다 | 코드 테스트 완료 |
| FR-09-04 | 주의 메모를 처리한다 | 무릎·허리·어깨 관련 운동을 보수적으로 제외하고, 의료 관련 메모는 계획 생성을 중단한다 | 코드 테스트 완료 · 실제 시연 전 |
| FR-09-05 | 장애를 알린다 | AI 실패 시 대체 계획이라고 명시하고 메모가 있는 경우 검토 없이 계획을 만들지 않는다 | 코드 구현 · 화면 시연 전 |

| FR-09-07 | 기존 기록을 보존한다 | 새 계획 전 확인을 받고 취소 시 기존 계획을 유지하며 과거 운동 날짜를 보존한다 | 코드 구현 · 회귀 확인 전 |

### 3. 입력·처리·출력

사용자가 목표, 수준, 주당 횟수, 1회 시간, 장소, 운동 방식 및 선택적 참고 메모를 입력한다. 서버는 입력 범위를 확인하고, 해당 조건의 활성 운동 템플릿을 조회한다. 무릎·허리·어깨 메모에 해당하는 동작을 보수적으로 제외한 후보 ID를 Gemini에 전달한다. Gemini는 정해진 개수의 ID 배열만 반환하고, 서버는 길이·중복·후보 포함 여부를 다시 검증한다. 화면은 선택된 템플릿의 기존 제목·동작 요약·가이드를 사용한다.

입력 메모는 Gemini에 전송되므로 화면에서 전송 사실과 개인정보 입력 주의를 안내한다. AI가 응답하지 않거나 유효하지 않으면 서버는 후보 목록으로 대체 계획을 만들고 출처를 `fallback`으로 보낸다. 의료 관련 메모나 안전한 후보가 없는 경우 계획을 만들지 않는다. 운동 중 통증이 있으면 중단하고 부상·질환이 있으면 전문가와 상담하도록 안내한다.
