# AI트레이너 · 생성형 AI 기반 맞춤 운동 트레이너

**현재 프로젝트 버전: v0.4**  
**프로젝트 형태: 모바일 화면 중심의 웹 프로토타입**  
**저장소: [smj0928-creator/generative-AI-project](https://github.com/smj0928-creator/generative-AI-project)**

AI트레이너는 사용자의 운동 목표와 수준, 주당 운동 횟수, 1회 운동 시간, 운동 장소 및 운동 방식에 맞춰 주간 운동 계획을 확인하고 운동 진행 상황을 관리하는 모바일 웹 프로젝트입니다

현재 운동 계획은 실제 생성형 AI가 아니라 `data/workout-templates.json`에 저장된 운동 템플릿과 JavaScript 규칙을 이용해 생성합니다. 사용자 설정과 운동 기록은 브라우저 `localStorage`에 저장되며, 계정이나 서버를 통한 데이터 동기화는 아직 연결되어 있지 않습니다

| 버전 | 변경일자 | 변경 내역 — 이전 버전 대비 | 진행 상태 |
|---|---|---|---|
| **v0.1** | 2026-10-13 | 초기 PRD를 바탕으로 서비스의 주요 화면과 사용자 흐름을 와이어프레임으로 정리. 운동 목표 설정, 주간 운동 계획 확인, 운동 완료 및 진행 상황 확인 등 핵심 사용 흐름을 정의 | 기준 와이어프레임 |
| **v0.2** | 2026-11-03 | 와이어프레임을 바탕으로 모바일 웹 프로토타입 구성. 홈, 운동 계획, 운동 상세, 운동 기록·성장, 준비 체크리스트, 배지, 커뮤니티 시연 및 설정 화면 등 주요 기능을 연결하고 브라우저 저장 기능 적용 | 프로토타입 구현 |
| **v0.3** | 2026-11-10 | 운동 데이터를 JavaScript 코드와 분리해 `data/workout-templates.json`으로 관리하도록 변경. 운동 장소(홈트레이닝/헬스장)와 운동 방식(맨몸운동/기구 운동/혼합 운동)을 선택할 수 있도록 하고, 선택 조건에 맞는 템플릿을 사용해 주간 계획을 생성하도록 개선 | 기능 반영 |
| **v0.4** | 2026-11-17 | 화면 탐색 구조 개선 작업. 설정 화면은 상단 설정 아이콘을 통해 진입하도록 변경하고, 하단 네비게이션 바에는 마이페이지를 추가하는 방향으로 개편. 기존 운동 계획·기록 기능은 유지하면서 개인 정보와 개인 운동 정보를 확인하는 진입점을 분리할 예정 | **작업 예정 / 코드 반영 전** |

### 버전별 주요 변경 사항

#### v0.1 — 초기 와이어프레임

- 초기 PRD의 요구사항을 화면 구조와 사용자 흐름으로 구체화
- 주요 화면과 화면 간 이동 관계 정의
- 이후 프로토타입 개발 시 비교할 기준 화면으로 보존

#### v0.2 — 모바일 웹 프로토타입

- 주요 화면을 실제 브라우저에서 이동할 수 있도록 구현
- 운동 계획 생성 및 운동 상세 확인 흐름 구성
- 운동 완료 상태, 진행률, 배지 및 준비 체크리스트 구현
- 커뮤니티·리그·공개 루틴 등 발표용 데모 화면 구성
- 사용자 정보와 데모 기록을 브라우저 `localStorage`에 저장

#### v0.3 — 운동 조건 및 데이터 구조 개선

- 운동 목표별 템플릿 데이터를 JSON 파일로 분리
- JSON 파일을 불러오지 못할 때 사용할 JavaScript 기본 데이터 유지
- 홈트레이닝과 헬스장 선택 기능 추가
- 맨몸운동, 기구 운동, 혼합 운동 선택 기능 추가
- 운동 장소와 운동 방식이 모두 일치하는 템플릿을 주간 계획 생성에 사용

#### v0.4 — 화면 탐색 구조 개선

- 상단 설정 아이콘을 통해 설정 화면으로 이동하도록 변경 예정
- 하단 네비게이션 바에 마이페이지 추가 예정
- 설정 메뉴와 개인 정보 화면의 역할을 분리
- 기존 운동 계획 및 기록 기능은 유지
- **주의:** 이 버전의 화면 변경은 현재 작업 방향이며, 업로드된 프로젝트 코드에는 아직 반영되지 않음

### 2.2 제품 개요

AI트레이너는 운동을 시작하거나 운동 습관을 만들고 싶은 사용자가 자신의 운동 목표와 운동 조건에 맞는 주간 운동 계획을 확인하고, 운동 완료 기록과 진행 상황을 관리할 수 있도록 돕는 모바일 웹 프로젝트입니다

### 2.3 주요 대상 사용자

- 운동을 처음 시작하거나 운동 습관을 만들고 싶은 사용자
- 체력 향상, 체중 감량, 근력 강화, 유연성 향상 중 하나를 목표로 하는 사용자
- 운동 장소와 운동 방식에 맞는 계획을 확인하고 싶은 사용자
- 운동 완료 여부와 주간 진행 상황을 한곳에서 확인하고 싶은 사용자

### 2.5 v0.4 화면 및 정보 구조 변경안

v0.4에서는 기존 기능을 없애기보다 설정 화면과 개인 정보 화면의 진입 위치를 구분하는 것을 목표로 합니다

**상단 영역**

- 설정 아이콘 추가 또는 기존 상단 프로필 버튼의 설정 진입 기능 정리
- 설정 아이콘 선택 시 설정 화면으로 이동

**하단 네비게이션 바**

- 홈
- 플랜
- 함께
- 마이페이지

**마이페이지**

- 개인 프로필 및 사용자 정보 확인 영역
- 개인 운동 정보와 기록을 확인할 수 있는 화면 구성
- 세부 항목과 화면 배치는 팀 논의 후 확정

**설정 화면**

- 기존 설정 기능은 유지
- 하단 네비게이션 메뉴에서는 분리하고 상단 설정 아이콘으로 진입

> 마이페이지에 표시할 세부 정보와 설정 항목의 최종 구성은 팀에서 확정한 뒤 PRD와 실제 화면에 함께 반영합니다

## 4. 발표 및 검증 시 유의사항

- 프로젝트 이름에 AI가 포함되어 있지만 현재 운동 계획 생성은 실제 생성형 AI가 아닌 사전 정의된 JSON 템플릿과 JavaScript 규칙을 사용합니다
