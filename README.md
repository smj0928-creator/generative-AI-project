# AI트레이너 · 생성형 AI 기반 맞춤 운동 트레이너

**현재 프로젝트 버전: v0.6**  
**프로젝트 형태: 모바일 화면 중심의 웹 프로토타입**  
**저장소: [smj0928-creator/generative-AI-project](https://github.com/smj0928-creator/generative-AI-project)**

AI트레이너는 사용자의 운동 목표와 수준, 주당 운동 횟수, 1회 운동 시간, 운동 장소 및 운동 방식에 맞춰 주간 운동 계획을 확인하고 운동 진행 상황을 관리하는 모바일 웹 프로젝트입니다

현재 운동 계획은 실제 생성형 AI가 아니라 `data/workout-templates.json`에 저장된 운동 템플릿과 JavaScript 규칙을 이용해 생성합니다. Supabase 로그인·회원가입과 프로필 저장 코드가 추가됐으며, 운동 계획과 완료 기록은 여전히 브라우저 `localStorage`에 저장됩니다. 계정 간 운동 기록 동기화는 아직 제공하지 않습니다.

### 버전별 주요 변경 사항

#### v0.1 — 초기 와이어프레임

- 초기 PRD의 요구사항을 화면 구조와 사용자 흐름으로 구체화
- 주요 화면과 화면 간 이동 관계 정의
- 이후 프로토타입 개발 시 비교할 기준 화면으로 보존

#### v0.2 — 모바일 웹 프로토타입

- 주요 화면을 실제 브라우저에서 이동할 수 있도록 구현
- 운동 계획 생성 및 운동 상세 확인 흐름 구성
- 운동 완료 상태, 진행률, 배지 및 준비 체크리스트 구현
- 커뮤니티·리그·공개 루틴 등 발표용 데모 화면 구성
- 사용자 정보와 데모 기록을 브라우저 `localStorage`에 저장

#### v0.3 — 운동 조건 및 데이터 구조 개선

- 운동 목표별 템플릿 데이터를 JSON 파일로 분리
- JSON 파일을 불러오지 못할 때 사용할 JavaScript 기본 데이터 유지
- 홈트레이닝과 헬스장 선택 기능 추가
- 맨몸운동, 기구 운동, 혼합 운동 선택 기능 추가
- 운동 장소와 운동 방식이 모두 일치하는 템플릿을 주간 계획 생성에 사용

#### v0.4 — 화면 탐색 구조 개선

- 하단 메뉴에 마이페이지를 추가하고, 마이페이지에서 앱 설정으로 이동하도록 구현
- 이번 주 운동·운동 현황·닉네임·배지를 마이페이지에 배치
- 플랜에는 전체 운동 계획과 주간 진행률을 유지

#### v0.5 — 계정 기반 추가

- Supabase 이메일 로그인·회원가입과 프로필 저장 코드를 추가
- 게스트에게 홈·플랜을 열어 두고 함께 탭에는 로그인 안내를 표시
- [v0.5 실행본](https://smj0928-creator.github.io/generative-AI-project/versions/v0.5/)을 별도 보존

#### v0.6 — 함께 화면 확장

- 로그인 회원이 함께 목록의 이름을 누르면 프로필과 최근 운동 기록을 볼 수 있게 함
- 다른 회원의 프로필과 기록은 가상 데이터로 표시하며 실제 Supabase 타인 기록과 구분

### 2.2 제품 개요

AI트레이너는 운동을 시작하거나 운동 습관을 만들고 싶은 사용자가 자신의 운동 목표와 운동 조건에 맞는 주간 운동 계획을 확인하고, 운동 완료 기록과 진행 상황을 관리할 수 있도록 돕는 모바일 웹 프로젝트입니다

### 2.3 주요 대상 사용자

- 운동을 처음 시작하거나 운동 습관을 만들고 싶은 사용자
- 체력 향상, 체중 감량, 근력 강화, 유연성 향상 중 하나를 목표로 하는 사용자
- 운동 장소와 운동 방식에 맞는 계획을 확인하고 싶은 사용자
- 운동 완료 여부와 주간 진행 상황을 한곳에서 확인하고 싶은 사용자

### 2.4 핵심 기능 요구사항

### 2.5 현재 화면과 접근 규칙

- 하단 메뉴는 **홈·플랜·함께·마이페이지**입니다.
- 홈에서는 로그인 없이 공개 트레이너 한 명의 루틴을 볼 수 있습니다.
- 마이페이지 상단에는 이번 주 운동, 아래에는 운동 현황·닉네임·배지를 표시합니다. 앱 설정은 마이페이지에서 이동합니다.
- 게스트가 함께 탭을 열면 **로그인 시 사용 가능** 안내가 보입니다. 로그인 회원은 가상 순위와 시연용 회원 프로필·최근 운동을 볼 수 있습니다.
- 타인의 실제 운동 기록을 공개하려면 기록 저장 방식과 공개 범위에 대한 별도 설계가 필요합니다.

| 구성 | 역할 | 현재 적용 방식 |

### 2.7 현재 구현 범위와 한계

**현재 구현된 범위**

- 모바일 웹 프로토타입
- 운동 목표 및 운동 조건 선택
- JSON 기반 운동 템플릿 불러오기
- 운동 장소와 운동 방식에 맞춘 규칙 기반 계획 생성
- 운동 계획 및 상세 확인
- 운동 완료 기록과 진행 현황 표시
- 배지, 준비 체크리스트, 커뮤니티 데모 화면
- Supabase 로그인·회원가입 코드와 로그인 회원용 함께 화면
- 브라우저 `localStorage` 저장

**아직 구현되지 않은 범위**

- 실제 생성형 AI API를 이용한 운동 계획 생성
- 운동 기록의 Supabase 저장 및 기기 간 동기화
- 다른 사용자의 실제 운동 기록 공개
- 실제 사용자 기반 커뮤니티 및 실시간 랭킹
- 실제 푸시 알림 발송
- 운동별 영상 콘텐츠의 전체 검증 및 연동

### 2.8 향후 개발 우선순위

1. Supabase에 운동 완료 기록을 저장하고 계정 간 동기화 구현
2. 회원의 공개 동의와 접근 정책을 정한 뒤 실제 함께 프로필·기록 연동
3. 운동별 이미지·자세 설명·영상 자료 검증 및 보강
4. 실제 생성형 AI 연동을 위한 서버 구성과 응답·안전 검증 방식 설계

## 4. 발표 및 검증 시 유의사항

- 프로젝트 이름에 AI가 포함되어 있지만 현재 운동 계획 생성은 실제 생성형 AI가 아닌 사전 정의된 JSON 템플릿과 JavaScript 규칙을 사용합니다
- 운동 계획과 사용자 기록은 현재 브라우저 내부에서 관리되며 계정 기반 서버 저장이 아닙니다
- 리그 순위, 공개 트레이너 및 친구 매칭은 실제 사용자가 연결된 기능이 아니라 시연용 데이터입니다
- v0.1은 최초 와이어프레임 초안입니다. `versions/v0.1/`은 이후 만든 초기 프로토타입을 비교용으로 복원한 폴더입니다.
- 현재 함께 화면의 타인 프로필·운동 기록은 시연용 가상 데이터이며 실제 회원 기록 공개는 아직 구현되지 않았습니다.
- 발표에서는 구현 완료 기능과 향후 개발 예정 기능을 구분해 설명합니다
