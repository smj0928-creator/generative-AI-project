# AI트레이너 프로토타입 v0.5

2026-11-17에 배포된 화면의 실행 파일을 보존한 버전입니다. `index.html`과 함께 `css/`, `js/`, `data/`, `assets/`, `supabase/`를 복사했습니다. [v0.5 실행하기](https://smj0928-creator.github.io/generative-AI-project/versions/v0.5/)

이 시점에는 Supabase 로그인·회원가입 및 프로필 저장 코드가 포함돼 있습니다. 게스트는 홈·플랜을 사용할 수 있고 함께 탭은 로그인 후 열립니다. 운동 계획과 완료 기록은 브라우저 `localStorage`에 저장됩니다. 이 버전은 별도의 Supabase 프로젝트를 만들지 않으므로 루트 프로토타입과 동일한 인증 프로젝트 및 브라우저 저장 공간을 공유할 수 있습니다.

변경 이력과 버전 비교는 [프로젝트 README](../../README.md)를 참고하세요. 비밀 키와 데이터베이스 비밀번호는 클라이언트 파일에 넣지 않습니다.
