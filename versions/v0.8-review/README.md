# AI트레이너 v0.8 검토본

이 폴더는 피드백 2차를 반영한 **확정 전 검토용 시연본**입니다. 당시 배포본인 v0.7은 `versions/v0.7/`에 보존했습니다.

2026-11-18에 검토를 마치고 확정한 실행본은 [저장소 루트](../../index.html)와 [`versions/v0.8/`](../v0.8/)에 있습니다. 이 폴더는 확정 전 비교 기록으로 남깁니다.

## v0.7 대비 변경

- 홈에서 중복 통계 대신 다음 운동을 바로 확인하고 상세를 열 수 있습니다.
- 주간 운동과 달성률은 `내 운동`, 완료 통계와 배지는 `마이페이지`에 배치했습니다.
- 계획 입력 화면에 참고용 메모의 한계와 통증·부상 안전 안내를 표시합니다.
- 계획을 다시 만들 때 완료 상태 변경을 확인합니다.
- 운동을 한 번도 완료하지 않았다면 리그 순위 대신 시작 안내를 보여 줍니다.
- 하단 메뉴를 `내 운동`으로 바꾸고 접근성 이름을 추가했습니다.
- 로그인 및 설정의 데이터 저장 안내를 현재 구현에 맞게 고쳤습니다.
- 로그인·회원가입에서 빈 입력, 이메일 형식, 짧은 비밀번호를 해당 입력칸 아래 빨간색으로 안내합니다. 서버 오류도 한국어로 안내합니다.

## 검토할 점

- 운동 추천은 여전히 JSON/Supabase 템플릿을 선택하는 규칙 기반 방식입니다. 생성형 AI 호출은 아직 구현하지 않았습니다.
- 참고용 메모는 추천 결과에 반영되지 않습니다. 부위별 제한 선택 기능은 다음 검토에서 결정해야 합니다.
- 리그, 순위, 공개 트레이너 인기도, 비슷한 운동 친구 카드와 시연용 타인 프로필은 가상 데이터입니다. 초대 코드로 추가한 실제 친구와 구분합니다.
- 계획 재생성 시 현재 계획의 완료 상태가 초기화됩니다. 과거 완료 날짜는 달력에 남지만 별도 운동 기록 목록은 없습니다.
- 보안을 위해 서버가 이메일 미가입과 비밀번호 불일치를 동일한 인증 실패로 반환하면 두 원인을 단정하지 않고 함께 안내합니다.

## 연속 운동 달력과 친구 기능 검토

- 마이페이지에 월별 달력과 실제 운동 완료 날짜를 표시합니다. 완료 취소 시 해당 날짜의 기록도 사라집니다. 계획을 다시 만들어도 과거 완료 날짜는 남습니다.
- 연속 일수는 운동 횟수가 아닌 **서로 다른 날짜**를 기준으로 계산합니다. 이전 버전에서 날짜를 기록하지 않은 게스트 운동은 과거 날짜를 추측해 채우지 않습니다.
- 로그인 회원은 `함께` 화면에서 8자리 초대 코드로 친구를 요청하고 수락·거절·삭제할 수 있도록 화면과 코드를 준비했습니다. 수락한 친구끼리만 연속 운동 일수를 비교합니다.
- **Supabase 적용 완료:** 친구 초대·요청 테이블과 접근 규칙을 `ai-health-trainer` 프로젝트에 적용했습니다. 설정 파일은 [`supabase/v08-friends.sql`](../../supabase/v08-friends.sql)입니다. 두 로그인 계정을 사용한 요청·수락 실사용 검증은 아직 남아 있습니다.
